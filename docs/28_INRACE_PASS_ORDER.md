## 4. 结论与遗留

**已钉死（实测 ✓）**：
1. 赛道内每帧 **10 次渲染目标切换**，`RT` 与深度面**严格 1:1 配对** ✓
2. 其中 **9 次来自 `0x504710`**（A/B 交替，含一次连续 B）✓
3. **第 10 次来自 `0x504a20`，每帧恰好一次** ✓ —— 即每帧唯一的离屏通道 ✓
4. 帧循环由 `0x5001f0` 收尾（`Present`）✓
