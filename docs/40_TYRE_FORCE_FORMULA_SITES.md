# 40 · 轮胎力公式的读取点（槽语义实证）

> 前几轮用 setter 偏移与 Java 索引表**推断**了槽语义（`docs/37`）。
> 本轮找到了**真正读系数做计算**的三处代码 ⇒ 槽 2、槽 11 从「推断」升级为**实证**，
> 并确认了布局 `[obj + 0x20C + entry×144]` 与轮胎子对象步长 `0x1528`。

## 0. 为什么之前找不到（机制）

系数块**不是**用固定位移直读的。物理代码的形态是：

```asm
lea  eax, [eax + eax*8]      ; eax = entry * 9
shl  eax, 4                  ; ★ eax = entry * 144   （9 × 16 = 144）
lea  eax, [eax + esi + 0x20C]; ★ 实际基址
movss xmm, [eax + <4*slot>]  ; ★ 位移才是槽号
```

⇒ 扫描「位移」时会命中**基址 `0x20C` 早已被折叠进 `lea`** 的形态，
单纯搜 `0x20C` 或搜小位移都抓不到。**判据**：抓 `lea reg,[reg+reg*8]` + `shl reg,4`
这一对（×9 再 ×16 = ×144），它比 `imul reg,reg,0x24` 更常用（后者全镜像仅 2 处，
且都不是本用途）。`tools/find_x36.py` 实现了这个扫描；
**校准**：它在车辆物理区给出 5 处，其中一处正是已知的 `0x48D510`（`docs/39` 的写入点）。

## 1. ★★★ 三处读取点

### 1.1 `0x482004` —— 载荷归一化 + 滑移开方

```asm
0x482004  lea  eax, [eax + eax*8]
0x482007  shl  eax, 4                 ; eax = entry * 144
0x48200C  lea  eax, [eax + esi + 0x20C]   ; ★ 基址
0x482013  mov  [esp+0xA0], eax            ; 基址存栈（后面反复用）
0x482020  movss xmm0, [edi + 0x114]       ; 载荷类量
0x482028  divss xmm0, [eax + 0x2C]        ; ★★★ 槽 11
0x48202D  movss xmm2, [0x6E766C]          ; = 1.0
0x482035  comiss xmm2, xmm0 / jbe / movaps xmm2, xmm0
                                          ; xmm2 = min(1.0, load / coef[11])
0x48203D  fld  [esi + 0x148]
0x482043  fld  [esi + 0x134]
0x482049  fabs / fxch / fsqrt             ; ★ 平方和开方（滑移速度模）
0x48204F  fld  [0x7426C8]
0x482055  fmul st(2) / faddp / fstp [esp+0x14]
0x482069  fld  [0x7426C0] / fcompi / jbe  ; 与另一个常量比较
0x482078  divss xmm0, [0x7426C0] / mulss xmm0, xmm2
```

**读出来的物理量**：`min(1.0, load / coef[11])` —— 即**归一化载荷**（被 1.0 截顶），
随后与「滑移速度模」一起送进后续计算。

⇒ **槽 11 = maxLoad**（载荷归一化的分母）：**实证**。

### 1.2 `0x45BB15` —— 同一个槽，独立的第二处

```asm
0x45BB0F  lea  eax, [eax + eax*8]
0x45BB12  shl  eax, 4                       ; entry * 144
0x45BB15  divss xmm0, [eax + ebx + 0x238]   ; ★★★ 槽 11（0x238-0x20C = 0x2C）
0x45BB1E  addss xmm0, [0x6E7A70]
0x45BB26  mulss xmm0, xmm1
0x45BB2A  mulss xmm0, [edi + 0x308]
```

**又一次拿槽 11 当分母**，且用的是与 1.1 **不同的基址寄存器组合**（`eax+ebx` 而非
`eax+esi`）⇒ 两条独立代码路径同一语义。

### 1.3 `0x45AD94` —— µ 乘载荷并累加

```asm
0x45AD94  lea  eax, [eax + eax*8]
0x45AD97  shl  eax, 4                    ; entry * 144
0x45AD9A  movss xmm3, [eax + esi + 0x214]  ; ★★★ 槽 2（0x214-0x20C = 8）
0x45ADA3  mulss xmm3, [edx + 0x114]        ; × 载荷类量
0x45ADAB  addss xmm3, xmm2                 ; ★ 累加
0x45ADAF  movaps xmm2, xmm3
0x45ADB2  addss xmm1, xmm6
0x45ADB6  add  esi, 0x1528                 ; ★★ 轮胎子对象步长
0x45ADBD  jne  0x45AD30                    ; 循环
0x45ADC3  comiss xmm1, xmm2 / jbe
0x45ADC9  movss xmm1, [edi + 0x227C]
0x45ADD5  movss [edi + 0x227C], xmm1
```

**循环内 `acc += coef[2] × load`** ⇒ 槽 2 是**被乘的抓地系数**（µ）。

⇒ **槽 2 = µ / 地面抓地缩放**：**实证**（与 `docs/35` 的配方差值推断**独立一致**）。

## 1.4 补：1.1 里两个常量的实际值 + 公式更正（★ 已逐条仿真核对）

| 地址 | 值 | 在公式中的角色 |
|---|---|---|
| `0x7426C0` | **5.0** | 滑移量的**断点**（与 `fcompi` 比较，`0x482069`） |
| `0x7426C8` | **10.0** | ✗ **不是断点，是乘数**（`0x48204F` 的 `fmul`） |
| `0x7426C4` | 20.0 | 本函数**未引用**（相邻共享常量，勿混用） |
| `0x6E7A70` | 0.1 | 小 epsilon（1.2 里 `addss`） |
| `0x6E7A74` | 0.01 | 小 epsilon（1.1 里 `comiss`） |
| `0x6EC24C` | 0.05 | 下限钳位（1.2 里 `comiss`） |

★ **更正**：本文件旧版把 `0x7426C8` 记成「20.0 第二断点」，实测为 **10.0 乘数**；
20.0 在 `0x7426C4`，本函数不引用。见 `docs/44` §5。

⇒ 1.1 的完整形态为（x87 栈已逐条仿真验证，见下）：

```
nl   = min(1.0, load / coef[11])          // 归一化载荷，1.0 截顶
s    = sqrt([esi+0x148]) + 10.0 × |[esi+0x134]|
s    = s < 5.0 ? (s / 5.0 × nl) : (nl)    // 0x482069 分支
```

`[esi+0x134]` 已由 `docs/44` §2.3 定名 = **悬挂当前长度**；`s` 是「滑移 + 悬挂行程」的合成尺度。
`|·|` 来自 `0x482049` 的 `fabs`，`sqrt` 只作用于 `[esi+0x148]`（**不是** `sqrt(a²+b²)`——旧版此处亦误）。

**可复现的仿真核对**（x87 序列 `fld/fabs/fxch/fsqrt/fld/fmul st(2)/faddp st(1)`）：

| A=`[esi+0x148]` | B=`[esi+0x134]` | 仿真 `s` | `sqrt(A)+10|B|` |
|---|---|---|---|
| 4.0 | 0.3 | 5.0 | 5.0 ✓ |
| 0.0 | 0.0 | 0.0 | 0.0 ✓ |
| 9.0 | −0.2 | 5.0 | 5.0 ✓ |
| 1.0 | 0.5 | 6.0 | 6.0 ✓ |

## 6. 续查（第 4 个候选与函数内部）

### 6.1 `0x4BC96C` —— 无关（✗），但给出一条校准判据

```asm
0x4BC96C  lea eax,[eax+eax*8]
0x4BC96F  shl eax, 2          ; ★ ×9 ×4 = ×36 —— 是 **36 字节**，不是 144
0x4BC972  push eax / call 0x66659D        ; 分配
（之后按 12 字节三元组拷贝）
```

⇒ 它分配的是「36 **字节** 的元素」，与 Pacejka 的 144 字节条目无关。

★★ **校准判据**：`lea reg,[reg+reg*8]` 只是「×9」，**必须看后面的 `shl` 位数**：

| `shl` 位数 | 总步长 | 用途 |
|---|---|---|
| `shl 4` | ×144 | ★ Pacejka 条目（36 槽） |
| `shl 2` | ×36 字节 | 另一类 36 字节结构（本处） |

盲扫 `lea *9` 会同时命中两者 —— 必须用 `shl` 值过滤。

### 6.2 `0x45BB15` 的下游 —— 三分量线性插值

`0x45BB85` 起把 `[esi+0x8C]` 的三个分量取出，调 `0x4BD590` / `0x4BB100`，
然后逐分量 `x = x * [0x6ED7E0] + 插值结果` ⇒ 一次**线性插值/平滑**
（轮子接触点或悬挂位置一类）。**没有新的槽**。

### 6.3 `0x482004` 函数内部的其它浮点访存

| 位置 | 访存 | 备注 |

## 7. ★★★ 槽 2 / 槽 3 的运行时公式（本轮实证解出，替换"语义未定"）

**位置**：巨型函数 **`0x47C010`**（28,208 字节 = 车每帧更新主函数）内的 `0x482004`–`0x4820F8`。
系数块索引：`lea eax,[eax+eax*8]; shl eax,4` ⇒ **`idx × 144` 字节**；块基址 = `轮 + 0x20C`
（⇒ 槽 11 = `+0x2C`、槽 2 = `+0x8`、槽 3 = `+0xC` 与 `docs/37/38` 完全一致 ✓）。

### 7.1 原文（逐行）

```asm
0x482020  movss xmm0, [edi + 0x114]      ; ★ 轮荷（已定名）
0x482028  divss xmm0, [eax + 0x2c]       ; ★★★ 槽 11 = 归一化分母 ⇒ L = 轮荷 / 槽11
0x48202d  movss xmm2, [0x6e766c]         ; = 1.0
0x482035  comiss xmm2, xmm0 ; jbe …      ; ★ xmm2 = min(1.0, L)          ← 载荷比钳位 ≤1
0x48203d  fld [esi + 0x148]
0x482043  fld [esi + 0x134] ; fabs       ; ★ 悬挂长度（绝对）
0x48204d  fsqrt                          ; √[esi+0x148]
0x48204f  fld [0x7426c8] = 10.0
0x482055  fmul st(2) ; faddp              ; ★★ s = √(轮+0x148) + 10·|悬挂长度|
0x482069  fld [0x7426c0] = 5.0           ; ★ 断点 5.0
0x482073  jbe 0x482087                    ; if (s <= 5.0) 跳过
   0x482075  xmm0 = s / 5.0
   0x482080  xmm0 *= xmm2
   0x482084  xmm2 = xmm0                  ; ★★ 否则 xmm2 = min(1,L) · s/5
0x482087  comiss xmm2, [0x6e7a74]=0.01
0x48208e  jbe 0x482116                    ; if (xmm2 <= 0.01) 走另一支（不写槽）
0x482094  xmm0 = [esi + 0x158]            ; ★ 轮胎新字段 +0x158
0x48209c  xmm3 = [0x7426c4] = 20.0
0x4820a7  xmm0 /= [0x742958] = 15.2       ; ★ 新常量 15.2
0x4820af  xmm0 *= [esi + 0x15c]           ; ★ 轮胎新字段 +0x15C
0x4820b7  jbe 0x4820c1                    ; if (20.0 <= s) 跳过
   0x4820b9  xmm0 /= 20.0 ; xmm0 *= s      ; ★ 否则 ×(s/20)
0x4820c5  xmm1 = [0x6ec4a8] = 0.99        ; ★ 新常量 0.99（下半钳位）
0x4820d8/0x4820ee  ; max(xmm0, 0.99)
0x4820f3  movss [eax + 0xc], xmm0         ; ★★★ 写回槽 3
0x4820f8  movss [eax + 8], xmm2           ; ★★★ 写回槽 2（µ）
```

### 7.2 ★★ 解出的公式

```
L      = 轮荷([轮+0x114]) / 槽11
µ(槽2) = min(1, L) · ( s > 5.0 ? s/5.0 : 1.0 )
槽3    = max( ([轮+0x158] / 15.2) · [轮+0x15C] · ( s > 20.0 ? s/20.0 : 1.0 ) , 0.99 )

s      = √([轮+0x148]) + 10·|悬挂长度([轮+0x134])|      （实测，与 docs/44 §5 一致 ✓）
```
* **槽 2 = µ，每帧被重算并写回**（⇒ 与配方里的值无关，是**运行时量**）✓ 与 `docs/39` "槽 2 每车运行时覆盖" 独立一致。
* **槽 3 = 由两个轮胎字段与滑移推出的量，下限 0.99**（默认 `-0.0005` 只是初值）✓ 回答了 `docs/41` §6 的 ✗ 项。
* **µ 的分段点在 `s = 5.0`**、槽 3 在 `s = 20.0` ⇒ 两个断点常量 `0x7426C0=5.0` / `0x7426C4=20.0`（后者**终于被引用**）。

### 7.3 ★★★ "轮胎行"结构（力 → 求解器的通道）

同一段还往**全局行数组 `0x771CF8`** 写一条 28 字节（`0x1C`）的记录，**数组唯一引用点 = `0x4820D0`**：

```asm
0x4820cf  eax = idx*0x1c + 0x771CF8
0x4820e5  [eax + 0x00] = 0                  ; 行类型 = 0（轮胎）
0x4820eb  [eax + 0x04] = &[轮 + 0xA8]       ; ★ 指向轮的 +0xA8 向量（对应 getter 0x67F580 的偏移！）
0x4820f3  [eax + 0x0C] = 槽3值
0x4820f8  [eax + 0x08] = µ（槽2值）
0x482105  eax += 0x10
0x482108  [eax + 0x00] = [edi + 0x00]       ; edi 每轮 += 0x80
0x48210d  [eax + 0x04] = [edi + 0x04]
0x482113  [eax + 0x08] = [edi + 0x08]
```

⇒ **行 = `{ int type=0; void* p = &[轮+0xA8]; float µ; float slot3; float a,b,c; }`**（7 dword）。
**这是轮胎力与求解器/接触系统之间的数据接口**，重制时对应"每轮生成一条摩擦行"。
