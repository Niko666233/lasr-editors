# 39 · Pacejka 默认模板（36 槽完整值）

> 来源：`0x48CA2F` 处 `mov esi, 0x742948` + `mov ecx, 0x24` + `rep movsd`
> —— 引擎在装载轮胎数据时，先**从一张静态模板拷 36 个 float（144 字节）**当默认值，
> 再逐条 `memcpy` 覆盖。⇒ `0x742948` 就是**出厂默认系数向量**，静态可读。

## 2. ★★★ 与 Java 侧三级互证

### 2.1 槽 22/23/24/25/26 —— 逐位吻合

```java
common_pacVarIdxs = {15, 16, 26, 24, 25, 22, 23}
common_pacVars    = {1000, 6000, 10.0, 0.0, 0.0, 1.0, 1.0}
                     →    →    ↑     ↑     ↑     ↑     ↑
                    15   16   26    24    25    22    23
```

| 槽 | Java `common` 值 | 静态模板值 | 一致？ |
|---|---|---|---|
| 22 | 1.0 | 1.0 | ✓ |
| 23 | 1.0 | 1.0 | ✓ |
| 24 | 0.0 | 0.0 | ✓ |
| 25 | 0.0 | 0.0 | ✓ |
| 26 | 10.0 | 10.0 | ✓ |

两条判据**来源完全独立**（Java 常量表 vs `.data` 静态模板）⇒ 槽号映射无误。

### 2.2 ★ 槽 15/16 的「冲突」已定案：`common` 是**运行时覆盖**

| 槽 | Java `common` | 静态模板 | 结论 |
|---|---|---|---|
| 15 | 1000 | **3000.0** | ✗ 不一致 |
| 16 | 6000 | **1000.0** | ✗ 不一致 |

⇒ `common_pacVarIdxs` 并**不是**"模板里就有的常量"，而是**运行时写入**：模板给出
默认值（3000 / 1000），随后 Java 侧用常量（1000 / 6000）**覆盖**。
`docs/38` §6.2 记录的"未验证冲突"在此**结案**。

## 3. 装载路径（本轮反汇编）

```asm
0x48CA0C  push 0x900            ; 分配 2304 B = 16 × 144
0x48CA11  call 0x66659D         ; 分配器
0x48CA19  mov  [esi+0x330], eax ; ★ pacdata 指针存进 +0x330
0x48CA20  mov  edx, [esp+0x10]
0x48CA24  mov  eax, [edx+0x330] ; 取**源对象**的 pacdata 指针
0x48CA2A  mov  ecx, 0x24        ; 36 dword
0x48CA2F  mov  esi, 0x742948    ; ★★ 默认模板
0x48CA38  rep movsd             ; 36 floats → 栈上临时块
0x48CA43  push ecx / push eax   ; (dst, src, 144)
0x48CA47  call 0x666C10         ; memcpy(dst = base+ebx, src = 栈上块, 144)
0x48CA4C  add  ebx, 0x90        ; 步进 144
0x48CA55  cmp  ebx, 0x900       ; ★★ 16 次 ⇒ 16 套系数
0x48CA5B  jl   0x48CA20
0x48CA6C  mov  eax, [esi+0x330]
0x48CA78  movss [eax+8], xmm0   ; 在 pacdata 头 +8 处写一个 float
0x48CA81  add  ecx, 0x334       ; ★ 外层步进 0x334（另一层结构）
```

★ **两个不同的系数数组**（勿混）：

| 数组 | 条目数 | 每条 | 位置 | 谁用 |
|---|---|---|---|---|
| **运行时 pacdata** | **16** | 144 B | 分配后由 `+0x330` 指向 | 本函数装载 |
| **车辆主表** | **32** | 144 B | 源对象 `+0x4880` | `docs/38` §1 的循环 |

★ `16` 与 `PacejkaGlobals.pacVarIdxs` 的 **16 项**同值；`32` 与 `docs/20`
的槽位上限 `[0,32)` 同值。两个数字**各自都有独立旁证**。
