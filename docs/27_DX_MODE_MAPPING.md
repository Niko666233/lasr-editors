## 3. 与 `shader.dat` 175 条的对应（docs/22 / docs/25 的落点）

| 档位 | 使用的着色器集合 | 证据 |
|---|---|---|
| DX8 (`1.1`) | **`ps.1.1` × 50 + `ps.1.4` × 6**（56 条）+ 对应 `.vsh` | `shader.dat` 分类统计 ✓ |
| DX9 (`2.0`) | **`ps.2.0` × 17 + HLSL 源 × 26** + 对应 `.vsh` | 同上 ✓ |
| DX7 (`N/A`) | 固定功能管线（无着色器 ⇒ 不需要 shader 条目） | 与 `GFX_INIT_NO_DX7_CARD` 错误串一致 ✓ |

⇒ `shader.dat` 里的两套**不是**"构建残留"，而是**两档后端各自需要** ✓✓（本轮由档位映射反向确认 ✓）。
⇒ 用户实机情报「ReShade 在 DX8/DX7 下正常、DX9 下花屏」由此得到解释方向 ✓：
DX9 档下引擎把设备包在自己的渲染接口里（`docs/26`），而 DX8 档走的是更"常规"的调用形貌 ✓。
